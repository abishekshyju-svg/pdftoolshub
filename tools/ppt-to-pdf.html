Frequently Asked Questions

PDF is a static format, so animations and transitions are not included. Each slide is captured as a static page showing all elements in their final state.

By default, only the slide content is converted. Speaker notes are not included in the PDF output to keep the document focused on visual content.

Embedded videos cannot be played in PDF format. The first frame of each video will appear as a static image in the converted PDF.
